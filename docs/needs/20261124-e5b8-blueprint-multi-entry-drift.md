# 项目蓝图深化——多入口组织、广谱漂移检测与漂移信号持久载体

## 背景与业务目标

- 承接关系：need 20261124-a727（项目蓝图能力）round 1 已全链交付单入口退化形态（验收 20261124-8b7c passed，need fulfilled）；蒸馏折回的「下一轮建议」明确后续轮次 = 多入口完整目录结构深化、广谱漂移检测、漂移信号持久标记载体。本 need 是该建议的需求驱动落地。
- 痛点延续（源自 a727 用户原话）：多入口项目「可能有多个应用入口，这些应该分开按入口分开蓝图。每个应用入口的蓝图的六类内容可能各不相同（因为使用者不同）」——round 1 退化形态不建入口层，多入口项目无从按入口分册；漂移检测 round 1 只覆盖 ADR accepted 一类，架构漂移的其他冲突无人发现；漂移信号无持久载体，亮牌被推迟即随会话丢失。
- 成功标准（须可核销）：
  1. 多入口项目的会话经 AGENTS.md 蓝图指针定位命中入口，只读该入口主册 + AGENTS.md 即答该入口核心设计问题（跨入口问题加读项目主册）——承 a727 成功标准 1 的多入口全形态。
  2. 蓝图过期漂移在施工装载 / 验收走查 / 手动回写三处任一被发现即成为持久标记行，不因会话结束丢失；回写后标记行消解留痕。
- 不做的代价：多入口项目蓝图退化为单入口混装（六类内容无法按使用者分册）；漂移只在 ADR 取代一类被发现，蓝图腐化回到 a727 立项痛点。

## 干系人与用户

- 读者侧 Actor（承 a727）：AI 新会话（按命中入口读入口主册答设计问题）、新接手的人（听设计原则与取舍）、开发中的会话（施工读者，按入口最小必要面装载）。
- 生产侧 Actor：
  - dev-blueprint：入口层立册（入口判定亮牌 + 拍板 → 入口目录与入口主册）、「待回写漂移」标记行区维护、回写消解。
  - 漂移检测者三处（用户 2026-11-24 按推荐拍板）：dev-implement（开工装载时对照发现）、dev-accept（使用方走查轴装载蓝图对照发现）、dev-blueprint（手动回写时自查发现）。
- 入口清单确认：亮牌识别 + 用户拍板，禁止代挑（承 a727 D16）。

## 系统能力需求

- FR-1 **多入口目录结构**：docs/blueprints/ 下项目主册（入口索引 + 跨入口共享面）+ 每入口一个目录（入口主册 = 该入口六类内容 + 入口级按需分册）；entry_slug 启用；单入口退化形态保留（承 a727 D14/D16 的全形态落地）。
- FR-2 **共享面判定**：跨入口共享内容（全局架构原则、共享领域概念、共享模块）归项目主册或项目级分册；入口内容自治不重复；共享模块清单升级承载入口归属（承 a727 缺口 1 载体的多入口形态）。
- FR-3 **按入口装载**：dev-implement 开工装载 = 改动面与入口模块归属匹配 → 命中入口的入口主册 + 命中模块册（跨入口改动加装项目主册）；未命中 / 未登记亮牌建议补登记，不拦截开工（承 a727 FR-7 升级）。
- FR-4 **广谱漂移检测三处**：dev-implement 开工装载时对照发现、dev-accept 使用方走查轴装载蓝图对照发现、dev-blueprint 手动回写时自查发现；任一处发现即写持久标记行。
- FR-5 **漂移信号持久载体**：项目主册「待回写漂移」标记行区（每行 = 发现点 + 冲突对象引用 + 日期）；回写后标记行转消解留痕；权威序不变——蓝图与最新轮次产物冲突以轮次产物为准（承 a727 D8）。
- FR-6 **术语按入口归册落地**：入口主册含术语节（承 a727 FR-9 的多入口形态）；跨入口同名不同义合法。

## 场景

主流程：

- **S1 多入口诞生**：Given 消费项目走完 dev-design 分析走查批准 / When 亮牌确认且入口判定拍板为多入口 / Then 项目主册 + N 个入口目录（各含入口主册）落盘，AGENTS.md 指针含入口索引，术语迁册归各入口术语节（FR-1、FR-6）。
- **S2 按入口施工装载**：Given 多入口蓝图在盘 + 带「改动面」工票 / When dev-implement 开工 / Then 装载命中入口的入口主册 + 命中模块册，不装未涉入口；跨入口改动加装项目主册（FR-3）。
- **S3 漂移发现到消解**：Given 蓝图某册与最新轮次产物冲突 / When 装载、走查、自查任一处发现 / Then 主册标记行区写入标记行；dev-blueprint 回写后该行转消解留痕 + 修订记录段追加一行（FR-4、FR-5）。

异常流：

- **E1 入口判属争议**：亮牌列候选 + 用户拍板 + 禁止代挑（承 a727 E4；FR-1）。
- **E2 单入口退化**：判定单入口或不设入口 → 不建入口层，标记行区仍在项目主册（承 a727 D16；FR-1、FR-5）。
- **E3 标记行长期未消解**：手动回写时自查集中亮牌列出未消解标记行，逐行处置（FR-4、FR-5）。

## 假设与风险

- R1 **多入口判定成本持续存在**（承 a727 R2）：应用面边界不清时判定成本在多入口项目持续；处置 = 亮牌 + 拍板，样板项目首跑观察实测。
- R2 **检测三处依赖接线纪律**：三处检测句任一漏改则检测失效回退——缓解 = 静态守护扩围（守护面候选清单已随 a727 蒸馏折回在 need，实现期按需扩入）。
- R3 **300 行阈值含标记行区**：标记行区行数计入主册尺寸；阈值实测校准留样板项目首跑，调参不改能力语义。
