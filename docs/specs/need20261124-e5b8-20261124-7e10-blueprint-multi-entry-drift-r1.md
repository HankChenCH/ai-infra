# 项目蓝图深化 round 1：多入口组织、广谱漂移检测与漂移信号持久载体

## 问题陈述

a727 round 1 交付的是单入口退化形态：多入口项目（多个应用面、使用者不同）的蓝图无从按入口分册——六类内容混装一张主册，「分开按入口分开蓝图」的需求未兑现；漂移检测只覆盖 ADR accepted 一类（supersede 冲突），架构漂移的其他冲突（模块地图变化、领域概念变化）无人发现；漂移信号没有持久载体——亮牌被推迟即随会话丢失，蓝图腐化无从累积可见。need 20261124-e5b8（承 a727 蒸馏「下一轮建议」）已 confirmed，本轮落全形态。

## 方案

dev-blueprint 技能深化：入口层立册（入口判定拍板为多入口 → 项目主册 + 每入口子目录、入口主册落子目录、主册增「入口索引」节）、按入口装载规则升级（模块地图增入口归属列）、漂移信号持久载体（主册「待回写漂移」标记行区：发现即写行、回写消解留痕）、回写自查扩未消解标记行集中亮牌。三处检测接线：dev-implement 开工装载对照发现即写行、dev-accept 使用方走查轴材料清单扩蓝图对照、dev-blueprint 手动回写自查。dev-clarify 双语态句升级为按入口登记；GLOSSARY 双份登记「漂移信号」词条 + 使用方走查轴词条扩围；setup-workspace assets AGENTS 模板指针行现状化（去「round 2 启用」陈旧标记）；静态守护测试扩围兜底。治理先行（蓝图 §11.25 条目修订 → 技能）。门禁、sdlc 路由、dev-review、METHOD 零改动。

本轮范围（分轮提议，待用户确认）：FR-1…FR-6 全量单轮——多入口结构与检测载体互为表里（装载按入口归属匹配、标记行区落主册），拆轮无收益；样板项目首跑（三链实操 + 阈值实测校准）归验收人工段，不进实现票。

## 用户故事

1. 作为多入口项目负责人，我想要每个应用入口成套蓝图（入口主册 + 入口级分册），以便各入口的使用者各得其所、六类内容按入口自治。
2. 作为开发会话（施工读者），我想要装载只命中本票涉足的入口（跨入口改动才加装项目主册），以便最小上下文仍含权威参照且不被无关入口淹没。
3. 作为施工会话，我想要开工装载对照时发现蓝图过期即写持久标记行，以便漂移不随会话丢失。
4. 作为验收代理，我想要走查轴装载蓝图对照发现漂移并写标记行，以便集成视角的过期被捕获。
5. 作为项目负责人，我想要未消解标记行在回写时被集中亮牌处置，以便标记不烂尾。
6. 作为读者（AI 新会话 / 新接手的人），我想要按命中入口读入口主册即答该入口核心设计问题，以便多入口项目保持「读一册懂一入口」。

## 实现决策

1. **治理先行（先改文档再改技能）**：套件蓝图新增修订记录条目——§11.25 dev-blueprint 条目深化修订（入口层立册、「入口索引」节、按入口装载归属列、检测三处、标记行区、回写消解）+ §5.2 所有权表 dev-blueprint 行措辞随更新 + §10.2 台账加行；实现顺序 = 蓝图条目修订 → docs/skills.md dev-blueprint 行描述升级（多入口形态）→ GLOSSARY 双份 → 技能与三处接线 → 静态守护扩围。§10.1 清单计数不变（无新技能，32 维持）。本票提交先于技能文本提交。
2. **入口目录结构（FR-1）**：判定拍板为多入口 → `docs/blueprints/<entry-slug>/` 每入口一个子目录，入口主册 + 入口级分册（模块册 / 术语分册）落子目录；项目主册与项目级分册（跨入口共享模块册 / 全局册）留顶层。entry_slug 用 ASCII 小写短横线（对齐 claim slug 惯例）。项目主册节清单升级为六节 + 标记行区：定位与边界 / **入口索引**（入口 slug → 使用者群体一句 → 子目录指针）/ 架构分层与模块地图（模块清单 + 入口归属列 + 共享模块清单行）/ 关键决策关联（跨入口共享决策）/**共享术语节**（跨入口共享概念）/ 修订记录段 / **待回写漂移标记行区**。单入口退化保留（承 D16）：不建入口层，主册仍含标记行区，入口索引节标「单入口退化」。设计引用：design 20261124-325d 分析段（a727 名下 analyzed）对象模型入口 / 入口主册 / 分册挂靠入口（0..1）与数据模型 BOOK entry_slug 全形态启用——e5b8 名下无 design，325d 作 prior art 引用，无偏离记录制适用。
3. **共享面判定（FR-2）**：跨入口共享内容（全局架构原则、共享领域概念、共享模块与共享决策）归项目主册或项目级分册；入口主册六类内容自治不重复。主册「模块地图」节升级 = 模块清单每行带入口归属（模块 → 入口 slug 映射；共享模块行标「共享」）——装载命中判定载体升级（承 a727 缺口 1 载体的多入口形态）。
4. **按入口装载（FR-3）**：dev-implement 开工装载句升级——改动面条目与主册模块地图归属列匹配 → 命中入口集：命中恰一入口 → 装项目主册 + 该入口主册 + 命中模块册；命中多入口（跨入口改动）→ 装项目主册 + 各命中入口主册 + 命中模块册；未命中 → 只装项目主册 + 亮牌建议补登记，不拦截开工。dev-review / dev-accept 按需装载句同口径升级（多入口时按需 = 命中入口主册）。
5. **检测三处接线（FR-4）**：① dev-implement 开工装载句补对照发现——装载的蓝图册与最新轮次产物冲突（模块地图与实际改动面失配、决策被新 ADR 取代等）→ 发现即写标记行（见实现决策 6）并亮牌告知；② dev-accept 使用方走查轴判断依据材料清单扩 docs/blueprints/（验收代理装载对照，发现即写标记行并留痕报告）；其 GLOSSARY「使用方走查轴」词条双份同批扩围（dual-copy-assets #4）；③ dev-blueprint 手动回写自查——每次回写收尾核对标记行区，未消解行集中亮牌逐行处置（need E3）。
6. **漂移信号持久载体（FR-5）**：项目主册「待回写漂移」标记行区 = 仪表盘语义——检测者（装载 / 走查会话）发现即写行，不需经 dev-blueprint 转手（need FR-4「发现即写」的字面承载；标记行是元数据不是蓝图内容，册内容的写者纪律不变：叙述与决策关联仍只由 dev-blueprint 与蒸馏第五路动笔）。行格式 = `- [待回写] <发现点> → <冲突对象引用>（<日期>）`；dev-blueprint 回写消解后该行改 `- [已消解 <日期>] <原行内容>` 留痕 + 主册修订记录段追加一行；权威序不变（蓝图与最新轮次产物冲突以轮次产物为准，承 a727 D8）。
7. **术语按入口归册（FR-6）**：入口主册含术语节（入口专属术语）；跨入口共享术语归主册共享术语节；归属模糊亮牌 + 拍板（承 a727 E4）。dev-clarify 双语态句升级：「蓝图不在盘登记 GLOSSARY 项目术语章」支不变；「蓝图在盘」支改为登记命中入口的入口主册术语节（共享术语登记主册共享术语节，判属争议亮牌）。
8. **AGENTS 指针与模板现状化（FR-1 / FR-3）**：dev-blueprint 立骨架写入句升级——多入口时 AGENTS.md 指针含真实入口索引（入口清单逐项列出）；setup-workspace assets AGENTS 模板指针行去「round 2 启用」陈旧括注、改多入口形态描述（模板无法预知入口清单，占位语义保留）。
9. **GLOSSARY 双份（实现决策 5 / 6 配套）**：项目术语章登记「漂移信号」词条（定义：蓝图与最新轮次产物冲突的待回写标记；载体 = 项目主册标记行区；检测三处；回写消解留痕；权威序承 a727 D8）；「使用方走查轴」词条判断依据清单扩 docs/blueprints/ 对照——两词条根 + assets 双份同批（dual-copy-assets #4 整文件 cp）。assets 的「项目术语章」仍零改动（澄清期暂存位语义不变，承 round 1 拍板）。
10. **静态守护扩围（R2 缓解）**：扩既有 test/unit/blueprint-wiring-static-guard.test.ts——正向锚新增：入口目录结构句、入口索引节句、归属列句、按入口装载句、检测三处句、标记行区句、消解留痕句、双语态入口句、走查轴扩围句、AGENTS 模板现状句；负向锚新增：「检测者代改蓝图册内容」「自动建入口不经拍板」类反转句零命中。锚词 = 本 spec 验收场景关键句字面；正向限定规格行、负向取全文（既有手法不变）。
11. **零改动声明**：check.sh 全部子命令、METHOD.md、sdlc SKILL.md 与 next-mode 路由表、dev-review SKILL.md（检测三处不含评审轴——need D2 拍板枚举）、skills/setup-workspace/assets/GLOSSARY.md 的项目术语章均零改动。
